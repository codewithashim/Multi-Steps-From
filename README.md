# Multi-Step Form

A responsive multi-step form built with Next.js, React Hook Form, Zod, and TailwindCSS.

## Features

- 3-step form with validation
- Personal Information, Address Details, and Account Setup steps
- Real-time validation with error messages
- Dark mode support
- Responsive design

## Prerequisites

- Node.js (v18 or higher)
- npm
